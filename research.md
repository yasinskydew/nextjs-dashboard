Добавление функции поиска.
Вот клиентские хуки Next.js, которые вы будете использовать для реализации функции поиска:

useSearchParams- Позволяет получить доступ к параметрам текущего URL-адреса. Например, параметры поиска для этого URL-адреса /dashboard/invoices?page=1&query=pendingбудут выглядеть так: {page: '1', query: 'pending'}.
usePathname- Позволяет прочитать путь к текущему URL-адресу. Например, для маршрута /dashboard/invoices, usePathnameвернет '/dashboard/invoices'.
useRouter— Обеспечивает программную навигацию между маршрутами внутри клиентских компонентов. Можно использовать несколько методов .
